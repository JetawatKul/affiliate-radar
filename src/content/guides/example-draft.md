เนื้อหานี้เป็น placeholder สำหรับทดสอบ layout และ SEO metadata ของ template บทความเท่านั้น
เนื่องจาก `draft: true` บทความนี้จะไม่ปรากฏในหน้ารายการ, sitemap หรือ build เป็นหน้า production
