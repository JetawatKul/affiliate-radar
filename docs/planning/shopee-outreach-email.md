# ร่างอีเมลถึง Shopee Affiliate Support (S0)

สถานะ: ร่างโดย Claude รอ Jay ตรวจ แก้ให้เป็นน้ำเสียงของตัวเอง แล้วส่งจากอีเมล/บัญชี Affiliate ของ Jay เอง
อ้างอิงคำถามจากหัวข้อ "สิ่งที่ Jay ต้องตัดสินใจหรือตรวจสอบ" ในแผนงานเฟส 1

ส่งผ่านช่องทางที่บัญชี Shopee Affiliate ของ Jay ใช้ติดต่อ support อย่างเป็นทางการ (ไม่ใช่โซเชียลหรือแชทบอทของ Shopee ChatGPT)

---

**หัวข้อ:** สอบถามเงื่อนไข Shopee Affiliate Open API และการแสดงข้อมูลบนเว็บสาธารณะ

เรียนทีมงาน Shopee Affiliate Program

ผม/ดิฉัน [ชื่อ Jay] เป็นสมาชิก Shopee Affiliate (ชื่อบัญชี: [เติมชื่อบัญชี]) กำลังวางแผนทำเว็บคอนเทนต์สำหรับผู้เริ่มต้นทำ Affiliate และอยากขอสอบถามเพื่อให้แน่ใจว่าทำถูกตามเงื่อนไขโปรแกรม ดังนี้

1. หากได้รับสิทธิ์ใช้ Shopee Affiliate Open API แล้ว สามารถนำข้อมูลสินค้า (ราคา, ค่าคอมมิชชัน, สถานะสินค้า) มาแสดงบนเว็บสาธารณะของตัวเองได้หรือไม่ และมีเงื่อนไขการแสดงผลอะไรบ้าง (เช่น ต้องอัปเดตความถี่แค่ไหน ต้องใส่ disclaimer อย่างไร)
2. ข้อห้ามเรื่องลิงก์ไปแพลตฟอร์มซื้อขายอื่นบนหน้าที่มีลิงก์ Shopee Affiliate (ข้อ 8.2 จ ในข้อกำหนดฉบับแก้ไข 20 ก.ย. 2569) ใช้บังคับระดับ "ทั้งเว็บ" หรือระดับ "หน้าเพจ" กันแน่ เช่น ถ้าหน้า A มีลิงก์ Shopee อย่างเดียว แต่หน้า B ของเว็บเดียวกันมีลิงก์แพลตฟอร์มอื่น จะถือว่าผิดเงื่อนไขหรือไม่
3. สามารถใช้คำว่า "Shopee" ในเนื้อหาบทความได้มากน้อยแค่ไหน (เช่น พูดถึงชื่อแพลตฟอร์มในบริบทรีวิว หรืออ้างอิงชื่อโปรแกรม) โดยไม่ผิดข้อ 2.3 ก เรื่องห้ามใช้ชื่อ/โลโก้ Shopee ในชื่อเว็บหรือโลโก้
4. คุณสมบัติและขั้นตอนการสมัครโปรแกรม MCN (Multi-Channel Network) ของ Shopee Affiliate มีอะไรบ้าง และเหมาะกับเว็บคอนเทนต์ขนาดเล็กที่เพิ่งเริ่มต้นหรือไม่
